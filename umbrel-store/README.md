# Personal OS: Umbrel app store

This folder is a community app store for umbrelOS. It contains one app, **Personal OS**.

To use it, publish this folder as its own repository (it must be the root of that repository), then in umbrelOS open the App Store, choose the menu at the top right, **Community App Stores**, and add the repository address.

Maintainers: `git subtree push --prefix umbrel-store <store-remote> main` publishes it from the main repository.
